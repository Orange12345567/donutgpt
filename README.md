# NEON VAULT — PRO DEMO

A polished, responsive arcade demo for GitHub + Vercel.

## Included
- Roulette
- Blackjack
- Neon Slots
- Plinko
- Crash
- Mines
- Dice
- Limbo
- 10M starting fictional chips
- K/M/B chip entry
- Developer credit controls
- Dark black / neon-green visual system
- Animated original CSS/SVG-style game art
- Responsive mobile layout
- Lightweight generated sound effects

## Deploy
1. Unzip this folder.
2. Create a GitHub repository.
3. Upload every file in this folder.
4. On Vercel, import the GitHub repository.
5. Deploy with no build command and no environment variables.

## Safety / scope
This is a fictional-credit arcade demo. It does not connect to DonutSMP balances, payment systems, cash-out, or real-money wagering.
The UI is inspired by modern online arcade/casino aesthetics but uses original artwork and code rather than copying a specific site's assets.
